Chicappd card backs

Use one scalable SVG for every card view and size. Both files have the same geometry, aspect ratio 5:7, and a centered C. mark. Switch only by global appearance preference if desired. Keep the same chosen back for every hidden card in a game.

card-back-light.svg  — pale sage with forest green C and coral dot
card-back-dark.svg   — forest green with pale C and coral dot
C-dot-mark.svg       — standalone brand mark for other UI surfaces
The PNGs are 600 x 840 previews/optional raster exports. Keep the SVGs as the source assets.

If a card element has another aspect ratio, fit the SVG into the existing card shape with preserveAspectRatio instead of stretching it. The illustration contains no rank, suit, or player-specific information.
