Chicappd icon pack

Light and dark appearance variants share the same source geometry.
Each .icns contains 16, 32, 128, 256, 512 and 1024 pixel representations, including Retina representations where supported.
The PNG masters are 1024 x 1024 with transparent space around the rounded tile. Additional PNG sizes are provided for other asset pipelines.
The two .icns files are separate appearance assets; merely placing both in an app bundle does not automatically switch between them. Configure appearance selection in your app or build pipeline.

Palette: light tile #E7EEE5, C #183E34, dot #E18D70; dark tile #163930, C #EFF4E9, dot #F29E7F.
